2. UNIFIED AUTHENTICATION, LOGIN & SECURITY (مرکزی لاگ ان و سیکیورٹی)
URL: http://localhost:3000/login
================================================================================
Features:
- Single Intelligent Login Screen: Automatically identifies whether the user is an Admin, Teacher, Student, or Parent, and immediately routes them to their portal.
- Persistent Session Lock: Keeps session active until explicit logout; prevents back navigation from exposing private data.
- Forgot Password Self-Recovery (/forgot-password):
  * Enter Username, Student ID, or Registered Email.
  * Generates secure, 15-minute single-use cryptographic token and sends reset link.
- Password Reset Screen (/reset-password):
  * Validates token and updates bcrypt password hash in database.
- Central /api/auth/me Service: Provides real live database profile for every logged-in user.

Buttons on Login & Auth pages:
[Sign In to Portal]           -> Authenticates credentials and logs into respective portal
[Forgot Password?]            -> Opens password recovery screen
[Send Reset Instructions]     -> Generates single-use token and sends email
[Confirm & Update Password]   -> Updates account password
[Back to Login]               -> Returns to login screen

3. ADMIN CENTRAL MANAGEMENT PANEL (ایڈمن پینل)
URL: http://localhost:3000/admin
================================================================================

3.1 Admin Dashboard (/admin)
- Summary Metrics: Total enrolled students, active teachers, today's attendance percentage, today's fee collection sum, and pending admissions.
- Consolidated Fast Stats API (/api/admin/dashboard-stats) with in-memory TTL caching.
Buttons:
[+ New Admission]         -> Opens new student enrollment form
[Record Payment]          -> Opens fee collection cash register
[ID Card Studio]          -> Opens student smart ID card generator
[Attendance Register]     -> Opens morning attendance register
[Broadcast Announcement]  -> Opens notice publication form
[🔑 Manage Passwords]     -> Opens login credentials & password manager
[⬅️ Back]                 -> Navigates to previous screen
[Leave Session / Logout]  -> Clears session cookies and logs out safely

3.2 Student 360° Directory (/admin/students)
- Complete directory of all enrolled students across all 13 classes.
- Server-side debounced search by Student Name, Roll Number, Student ID, or Class.
Buttons:
[Filter Class Dropdown]   -> Filters students by specific class
[View 360° Profile]       -> Opens full academic and fee profile of the student
[Login & Passwords]       -> Jump directly to edit this student's login/password
[ID Card Studio]          -> Jump directly to print this student's ID card
[+ New Admission & Enroll]-> Starts new admission process

3.3 Admissions Pipeline & 1-Click Enrollment (/admin/admissions)
- Pipeline stages: Submitted -> Under Review -> Approved -> Enrolled.
- Mandatory Student Photograph verification before enrollment.
- 1-Click "Approve & Enroll" Backend Transaction:
  1. Creates permanent Student record.
  2. Creates Parent relationship.
  3. Allots official Student ID (e.g. THMS-2026-000025).
  4. Allots Class Section Roll Number (e.g. 08-A-005).
  5. Generates Secure Opaque QR Token.
  6. Creates Student Portal User Account.
  7. Creates Parent Portal User Account.
  8. Assigns Fee Structure and generates initial fee invoice.
  9. Dispatches login details email to parents via Resend.
Buttons:
[Approve & Enroll Student] -> Executes atomic enrollment database transaction
[📱 Copy for WhatsApp]     -> 1-click copy of credentials to WhatsApp parents
[🖨️ Print Credentials Slip]-> Prints dual login credential slip for student & parent
[View ID Card]             -> Opens the generated official ID card

3.4 ID Card Studio & Smart QR Identity (/admin/id-cards)
- Dual-Sided Printable Cards:
  * Front Side: School crest, student photo, full name, father name, student ID, roll no, class, and section.
  * Back Side: Secure opaque verification QR code, emergency contact, validity, and principal signature.
Buttons:
[Print Single Card]        -> Prints single card on card printer / A4 sheet
[Bulk Print Class Cards]   -> Prints cards for the whole class simultaneously
[Download PDF / Image]     -> Downloads card file

3.5 Login, Gmail & Password Manager (/admin/users)
- Full administrative control over all user accounts (Students, Teachers, Parents, Staff, Admins).
- Filter by Role (ALL, STUDENT, TEACHER, PARENT, ADMIN).
- Search by Name, Student ID, Roll No, or Gmail.
Buttons:
[📋 Copy Username]         -> Copies portal username to clipboard
[📋 Copy Gmail]            -> Copies registered Gmail to clipboard
[🔑 Reset Password]:
   - [🎲 Generate Strong Password] -> Generates secure random password
   - [📱 Copy for WhatsApp]        -> Copies password message formatted for WhatsApp
   - [Update Password]             -> Updates password hash in database
[✏️ Edit Details]:
   - Edit Login Gmail / Email address
   - Edit Login Username
   - Toggle Account Status (ACTIVE / SUSPENDED)
   - [Save Changes]                -> Saves updated credentials to database

3.6 Fees, Invoices & 3-Slip Bank Vouchers (/admin/fees)
- Monthly tuition, admission fee, exam fee, and transport fee management.
- Real-time payment collection with partial payment and remaining balance tracking.
- Official 3-Slip Deposit Receipt:
  * School Copy (اسکول کاپی)
  * Bank / Accounts Copy (بینک کاپی)
  * Student / Parent Copy (طالب علم / والدین کاپی)
Buttons:
[+ Generate Monthly Invoices] -> Creates invoices for entire class in 1 click
[Record Payment]              -> Records cash/bank payment, updates balance, generates receipt
[Print Receipt]               -> Prints 3-part bank voucher slip

3.7 Smart Gate QR & Attendance Register (/admin/attendance)
- Live Camera / Barcode QR Scanner: Instantly verifies student identity and marks daily attendance.
- Duplicate Scan Protection: Database unique constraint prevents scanning the same student twice on the same day.
- Class-wise Manual Roll Call Register (Present, Absent, Late, Excused).
Buttons:
[Open Live QR Scanner]        -> Activates gate camera scanner
[Save Daily Register]         -> Saves class attendance to database
[Export Attendance Report]    -> Generates attendance summary

3.8 Teachers & Faculty Management (/admin/teachers)
- Complete directory of academic faculty, assigned subjects, classes, and employee IDs.
Buttons:
[+ Add New Teacher]           -> Adds teacher and automatically generates portal account
[Login & Passwords]           -> Direct shortcut to teacher credential management
[Assign Subjects & Classes]   -> Allocates curriculum subjects and sections

3.9 Academics, Timetable & 13 Classes (/admin/academics)
- Class management for Playgroup, Nursery, Prep, and Class 1 to Class 10 (Section A & B).
- Daily period timetables with room numbers and teacher assignments.

3.10 Examinations & Progress Report Cards (/admin/examinations)
- Exam schedules for Term Exams, Mid-Terms, and Annual Board exams.
- Subject-wise marks entry (Obtained Marks, Total Marks, Grade, GPA).
- Official Printable Report Card with school seal, class position, and principal remarks.

3.11 Announcements & Broadcast Notifications (/admin/announcements)
- Publish notices targeting All Students, All Parents, All Teachers, or Specific Classes.
- Automated push notification and email alerts.

3.12 School Settings & Branding (/admin/settings)
- Edit School Name, Code, Phone, Email, Campus Address, and Logo URL.
- Configure fee defaults and active academic sessions.
